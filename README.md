# Shikimori — Material 3 Expressive

A custom CSS theme for [Shikimori](https://shikimori.one/) inspired by Google's Material 3 Expressive design language.

## Themes

- **Material Expressive Light** — version 0.1 (available)
- **Material Expressive Dark** — planned

## Installation

1. Open Shikimori's custom CSS settings.
2. Open [`theme.css`](theme.css) and copy its contents.
3. Paste the CSS into the custom style editor and save.

The stylesheet imports Roboto from Google Fonts; an internet connection may be required to load that font.
