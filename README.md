# Shikimori — Material Design 3 Expressive

A custom CSS theme for [Shikimori](https://shikimori.one/) inspired by **Material Design 3 Expressive**. The project aims to bring its expressive visual language to the Shikimori interface through a considered color palette, rounded shapes, tonal surfaces, typography, and carefully styled interface elements.

## Themes

- **Light** — [`Light/shikimori-m3-expressive_v0.1.css`](Light/shikimori-m3-expressive_v0.1.css) — version 0.1, available.
- **Dark** — [`Dark/`](Dark/) — planned; not released yet.

## Installation

1. Choose a theme from the `Light` or `Dark` folder.
2. Open the CSS file and copy its contents.
3. Paste the CSS into Shikimori's custom CSS settings and save.

The current Light stylesheet imports Roboto from Google Fonts; an internet connection may be required to load that font.
