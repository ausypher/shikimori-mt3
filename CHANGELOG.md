# Changelog

All notable changes to this project are documented here.

## [0.2] - 2026-11-13

### Updated
- Published the current Material Design 3 Expressive Light stylesheet as `Light/shikimori-m3-expressive_v0.2.css`.
- Restored the native flat forum layout while retaining the theme's styling for quotes, editor controls, and other interface elements.
- Updated the README installation instructions to use the v0.2 stylesheet.

### Note
- Version 0.2 supersedes version 0.1. Use v0.2 for new installations and updates.
- The Dark variant is still planned and has not been released.

## [0.1] - 2026-11-13

### Added
- Initial release of the Material Design 3 Expressive Light theme for Shikimori.
- Separate `Light` and `Dark` directories for the theme variants.
- Dark variant placeholder; theme is planned and not yet available.

### Status
- Superseded by version 0.2.
