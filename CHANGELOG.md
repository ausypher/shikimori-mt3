# Changelog

All notable changes to this project are documented here.

## [0.6.1]

### Fixed
- Review tabs now stay within the content column and use distinct colors by review type: green for positive, blue for neutral, and pink for negative.
- Removed the protruding divider between the “Yes / No” helpfulness vote buttons; the buttons now use green and pink styling.

### Added and improved
- Styled review navigation as a Material 3 connected button group, with a tonal selected state and expressive shape morphing.
- Restyled the “Was this review helpful?” Yes / No controls as a connected pair with expressive outer and inner corner radii.
- Restyled “Load more” comments as a tonal pill button with state layers and shape morphing.
- Translated English CSS comments into Russian.
- Retained the v0.6.0 improvements: M3 state layers, expressive motion and shape morphing, refined quotes, spoiler particle animation, scrollbar fixes, and reduced-motion handling.

## [0.4.3] - 2026-11-25

### Updated
- Updated the README and installation instructions to use the published Light stylesheet `light/shikimori-m3-expressive_v0.4.3.css`.
- Synchronized the version metadata in the v0.4.3 stylesheet header.


## [0.4.2] - 2026-11-14

### Updated
- Moved the current Light stylesheet to `light/shikimori-m3-expressive_v0.4.2.css`.
- Updated repository documentation and installation links to version 0.4.2.
- Standardized the Light stylesheet directory name to lowercase `light`.

### Improvements
- Preserved the original white email notification badge with dark counter text.


## [0.3] - 2026-11-13

### Updated
- Published the current Material Design 3 Expressive Light stylesheet as `Light/shikimori-m3-expressive_v0.3.css`.
- Updated the README theme status, stylesheet links, installation import, and versioning information to v0.3.
- Removed the obsolete v0.1 and v0.2 stylesheet files. Version 0.3 is now the only available Light stylesheet.

### Improvements
- Preserved the native flat Shikimori forum layout while retaining theme styling for quotes, editor controls, and interface elements.
- Restored the original achievement layout and ensured achievement descriptions are not clipped.
- Refined the profile, poster, navigation, controls, and accessibility styling in the unified stylesheet.

### Note
- Version 0.3 is the current and recommended Light stylesheet.
- The Dark variant is still planned and has not been released.
